# Barber Brazil Pro

Create a fully customized barber website inspired by Brazilian barber culture. The website should be modern, premium, stylish, and simple to use. Use a dark luxury theme with Brazilian street/barbershop vibes: black background, gold/green accents, smooth animations, modern typography, and high-quality barber aesthetic.

The website has ONLY TWO MAIN PAGES:

1) INDEX PAGE (Customer Website)

- Beautiful landing page for the barber.

- Use the barber's Instagram style and branding from:

https://www.instagram.com/_braziiilyy___244__/

Sections:

- Hero section:

  - Barber name/logo

  - Professional barber image area

  - Short slogan

  - Button: "Book Appointment"

- About the barber

- Services section:

  - Haircut

  - Beard trim

  - Hair + beard combo

  - Other services

  - Prices editable from admin dashboard

- Gallery section for barber work

- Customer reviews section

- Location/contact section

- Instagram button

Reservation system:

- Customers can book an appointment directly from the website.

- Form fields:

  - Full name

  - Phone number

  - Select service

  - Select date

  - Select available time

  - Notes (optional)

- Show only available times.

- Prevent double bookings.

- After booking, show confirmation message.

- Store all reservations in database.

2) ADMIN DASHBOARD PAGE

Create a secure admin dashboard for the barber.

Features:

- Admin login page.

- Dashboard overview:

  - Today's appointments

  - Upcoming appointments

  - Number of customers

  - Total bookings

Reservation management:

- View all reservations in a calendar/list format.

- Show:

  - Customer name

  - Phone number

  - Service

  - Date

  - Time

  - Status

- Status options:

  - Pending

  - Confirmed

  - Completed

  - Cancelled

Admin actions:

- Confirm reservation

- Reject/cancel reservation

- Delete reservation

- Edit reservation

- Contact customer by phone button

- Add manual reservation

- Block unavailable hours

- Set working schedule

Working hours system:

- Admin can set:

  - Opening time

  - Closing time

  - Days off

  - Break times

- Automatically generate available booking slots.

Customization:

- Admin can edit:

  - Barber name

  - Logo

  - Photos

  - Services

  - Prices

  - Working hours

  - Contact information

Technical requirements:

- Fully responsive for mobile and desktop.

- Fast loading.

- Beautiful animations.

- Modern UI/UX.

- Use clean professional code.

Recommended stack:

Frontend:

- HTML/CSS/JavaScript or React

- Tailwind CSS for styling

Backend:

- Node.js + Express

Database:

- Firebase / Supabase / MySQL

Authentication:

- Secure admin login.

Create a complete working reservation website, not just a design prototype.

The final result should feel like a premium Brazilian barber shop website.
